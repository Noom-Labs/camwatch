Crie um sistema SaaS multi-tenant de monitoramento inteligente para câmeras IP Intelbras, focado em detecção de veículos em tempo real.

O sistema deve suportar DOIS modos de operação:

MODO 1 — CLOUD EVENTS
- Utiliza eventos inteligentes enviados pela própria câmera
- Compatível com Intelbras ONVIF
- Recebe eventos de:
  - detecção veicular
  - linha virtual
  - cerca virtual
  - movimento
- Sistema apenas processa eventos e envia notificações
- Baixíssimo consumo de CPU

MODO 2 — EDGE AI
- Um agente local roda próximo da câmera
- Captura RTSP
- Processa vídeo com IA localmente
- Detecta:
  - carro
  - moto
  - caminhão
- Usa YOLOv8n
- Envia apenas eventos para a nuvem
- Deve funcionar em:
  - Windows
  - Linux
  - Docker
  - Mini PCs
  - Raspberry Pi (modo otimizado)
